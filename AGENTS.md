# Правила проекта «Звук N» (для ассистента и для программиста)

Сайт вокальной школы «Звук N». Собирается из шаблонов и файлов с содержимым.
Владелец меняет только тексты и фото, вёрстку не трогает.

## Как всё устроено

```
zvukn-site/
├── src/
│   ├── content/          ← СОДЕРЖИМОЕ (тексты, цены, фото). Меняет владелец.
│   │   ├── site.yaml     ← общие настройки: адрес, меню, соцсети, какой вариант главной
│   │   ├── home.yaml     ← содержимое главной страницы
│   │   ├── home-v2.yaml  ← отличия главной для варианта 2
│   │   ├── home-v3.yaml  ← отличия главной для варианта 3
│   │   └── <страница>.yaml
│   ├── _includes/
│   │   ├── layouts/
│   │   │   ├── layout-main.njk   ← каркас главных страниц
│   │   │   └── layout-inner.njk  ← каркас внутренних страниц
│   │   ├── home-v1.njk   ← вёрстка главной, вариант 1
│   │   ├── home-v2.njk   ← вёрстка главной, вариант 2
│   │   ├── home-v3.njk   ← вёрстка главной, вариант 3
│   │   └── arrow.njk     ← значок-стрелочка (используется через include)
│   ├── pages/            ← страницы (шаблоны Nunjucks)
│   └── assets/           ← стили и скрипты (css, js)
├── static/               ← файлы, которые копируются как есть
│   └── assets/img/       ← все картинки (сюда же владелец кладёт новые)
├── admin/                ← панель управления для владельца
├── docs/                 ← инструкции
└── _site/                ← ГОТОВЫЙ САЙТ (создаётся сборкой, руками не правим)
```

Оригинал сайта (не трогать, только смотреть как образец):
`../restored/Default Project/zvukn-landing` (и `zvukn-hosting` — то, что выложено в интернет).

## Как собрать

```bash
export PATH="$HOME/.local/node/bin:$PATH"
cd zvukn-site
npx eleventy            # соберёт сайт в _site
npx eleventy --serve    # то же + живое обновление в браузере
```

## Правила (важные)

1. **Вёрстка не меняется при переносе содержимого.** Классы, порядок элементов,
   атрибуты `aria-*`, `data-abs`, `data-d`, `data-delay` — сохранять как в оригинале.
   Задача — заменить тексты/цены/картинки на значения из YAML, а не переписать разметку.
2. **Файл содержимого = имя данных.** `src/content/blog.yaml` доступен в шаблонах как `blog`.
   Папка данных настроена в `eleventy.config.js` (`dir.data: "content"`, чтение YAML — js-yaml).
3. **Ссылки** в содержимом пишутся как `/zanyatiya` (без `.html`) и пропускаются через
   фильтр `| url` — он сам добавит `.html` и не сломает якорь `/kontakty#zayavka`.
   Внешние ссылки (`https://…`) фильтр не трогает.
4. **Разметка в текстах.** Перенос строки — `<br>`, золотой курсив —
   `<span class="it gold">…</span>`. Такие тексты выводятся с фильтром `| safe`.
5. **Картинки**: путь вида `assets/img/имя.jpg` (без ведущего слэша), файлы — в `static/assets/img`.
6. **Тире и кавычки**: в текстах сайта используются «ёлочки» и длинное тире (—), как в оригинале.
7. **Не трогать**: `eleventy.config.js` (кроме случаев, когда нужен новый фильтр),
   `src/assets/css/*`, `src/assets/js/site.js`, `_site/`.
8. **Именование страниц**: файл `src/pages/o-pedagoge.njk` с `permalink: /o-pedagoge.html`
   заменяет оригинальный `o-pedagoge.html`.
9. **Проверка после правок**: собрать и сверить результат с оригиналом:
   `diff <(sed 's/^[[:space:]]*//' ОРИГИНАЛ | grep -v '^$') <(sed 's/^[[:space:]]*//' _site/СТРАНИЦА | grep -v '^$')`
   Различия допустимы только в ссылках, переносах строк и в отступах.

## Что менять, если владелец просит

| Просьба | Где править |
|---|---|
| Текст на главной | `src/content/home.yaml` |
| Цены, форматы занятий | `src/content/home.yaml`, раздел `formats` |
| Программа курса | `src/content/home.yaml`, раздел `program` |
| Отзывы | `src/content/home.yaml`, раздел `reviews` |
| Фотографии | `src/content/home.yaml` (`gallery.photos`) + файл в `static/assets/img` |
| Телефон, почта, адрес, соцсети | `src/content/site.yaml` |
| Меню сайта | `src/content/site.yaml`, раздел `menu` |
| Какой вариант главной показывать | `src/content/site.yaml`, поле `mainVariant` (1, 2 или 3) |
| Страница «О педагоге» | `src/content/o-pedagoge.yaml` |
| Страница «Занятия» | `src/content/zanyatiya.yaml` |
| Блог | `src/content/blog.yaml` + статьи в `src/content/posts/` |
| Заготовки статей («скоро») | `src/content/blog.yaml`, раздел `upcoming` |
| Ссылки в полноэкранном меню | `src/content/site.yaml`, раздел `menuSocials` |
| Контакты | `src/content/kontakty.yaml` |
| Политика конфиденциальности | `src/content/politika.yaml` |

После любой правки — собрать сайт (`npx eleventy`) и показать результат владельцу (`open _site/index.html`).

## Чего делать нельзя

- Переименовывать классы и файлы стилей — на них завязан вид сайта.
- Менять количество полосок в кнопке меню: их ровно три (`<i></i><i></i><i></i>`).
- Править файлы в `_site` — они перезаписываются сборкой.
- Трогать папку оригинала `restored/…` — это копия «как было».
