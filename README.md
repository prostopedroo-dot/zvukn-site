# «Звук N» — сайт вокальной школы

Сайт вокальной школы «Звук N» (Санкт-Петербург, педагог — Наталья Охочинская).
Это статический сайт: он собирается из шаблонов и файлов с текстами и получается
в папку `_site` — её можно открыть в браузере или выложить на хостинг.

**Страниц — 10** (плюс отдельные страницы статей блога):

- главная в трёх вариантах оформления (1 — тёмный с большой фотографией,
  2 — «Редакция», 3 — «Афиша»); какой вариант показывается — выбирается
  в настройках, рядом есть страницы просмотра каждого варианта и страница
  сравнения;
- о педагоге;
- занятия и стоимость;
- блог: список статей плюс сами статьи (каждая статья собирается отдельной страницей);
- контакты;
- политика конфиденциальности.

## Как посмотреть сайт

1. Двойной клик по `1-СОБРАТЬ-САЙТ.command` — соберёт сайт в папку `_site`
   (при первом запуске сам установит всё нужное).
2. Двойной клик по `2-ОТКРЫТЬ-САЙТ.command` — откроет готовую главную в браузере.

Третий скрипт, `3-ПАПКА-С-ТЕКСТАМИ.command`, открывает папку, где лежат все
тексты и цены сайта.

Если двойной клик открыл файл как текст (например, внутри OpenCode), запустите
скрипт из терминала:

```bash
open -a Terminal "1-СОБРАТЬ-САЙТ.command"
open -a Terminal "2-ОТКРЫТЬ-САЙТ.command"
```

## Как менять содержимое

Все тексты, цены, фото, адреса и меню лежат в папке `src/content/` — это
YAML-файлы, по одному на страницу. Статьи блога — в `src/content/posts/`
(обычные текстовые файлы). После правки снова запустите `1-СОБРАТЬ-САЙТ.command`.

Подробнее: [docs/КАК-ПРАВИТЬ-ВЛАДЕЛЬЦУ.md](docs/КАК-ПРАВИТЬ-ВЛАДЕЛЬЦУ.md).

Сайт уже опубликован по адресу <https://zvukn-school.netlify.app>. В проект
встроена панель управления (`/admin/`, Decap CMS) — в ней владелец правит тексты
и фотографии прямо в браузере, без работы с файлами. Панель заработает после
одноразового подключения (нужны бесплатный аккаунт GitHub и несколько кнопок
в Netlify) — пошагово: [docs/КАК-ОПУБЛИКОВАТЬ.md](docs/КАК-ОПУБЛИКОВАТЬ.md).

## Структура папок

```
zvukn-site/
├── src/
│   ├── content/      ← содержимое: тексты, цены, фото, статьи блога (меняет владелец)
│   ├── pages/        ← страницы (шаблоны Nunjucks)
│   ├── _includes/    ← каркасы страниц и вёрстка главной
│   └── assets/       ← стили и скрипты
├── static/           ← картинки и шрифты, копируются на сайт как есть
├── admin/            ← панель управления (Decap CMS)
├── docs/             ← инструкции
├── _site/            ← готовый сайт (создаётся сборкой, руками не правится)
├── 1-СОБРАТЬ-САЙТ.command
├── 2-ОТКРЫТЬ-САЙТ.command
└── 3-ПАПКА-С-ТЕКСТАМИ.command
```

## Технические команды

```bash
npx eleventy          # собрать сайт в _site
npx eleventy --serve  # собрать и открыть с живым обновлением в браузере
npm run clean         # удалить _site (следующая сборка создаст заново)
```

То же самое через npm: `npm run build` (сборка) и `npm start` (живое обновление).
Если компьютер не находит Node, сначала выполните:

```bash
export PATH="$HOME/.local/node/bin:$PATH"
```

## Оригинал сайта

Эталон «как было» лежит рядом, править его нельзя:

- `../restored/Default Project/zvukn-landing` — исходная вёрстка сайта;
- `../restored/Default Project/zvukn-hosting` — то, что выложено в интернет.

Сравнивать с ними результат сборки удобно так (см. также AGENTS.md):

```bash
diff <(sed 's/^[[:space:]]*//' ОРИГИНАЛ | grep -v '^$') \
     <(sed 's/^[[:space:]]*//' _site/СТРАНИЦА | grep -v '^$')
```
