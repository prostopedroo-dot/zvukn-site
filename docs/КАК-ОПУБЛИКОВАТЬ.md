# Как выложить сайт в интернет и включить панель управления

Этот файл — про то, как сделать так, чтобы владелец мог менять сайт сам
через браузер, а изменения сами появлялись в интернете.

**Коротко:** сайт уже опубликован по адресу `https://zvukn-school.netlify.app`.
Чтобы появилась панель управления, нужно один раз связать проект с бесплатным
хранилищем (GitHub) и включить вход по почте и паролю в Netlify.
Дальше всё работает само: правка → кнопка «Опубликовать» → через минуту на сайте.

Понадобится: аккаунт **GitHub** (бесплатный, создать за 3 минуты) и доступ
к аккаунту **Netlify**, где уже живёт сайт.

---

## Часть 1. Что нужно сделать вам (около 15 минут)

### Шаг 1. Завести аккаунт GitHub

GitHub — это бесплатное хранилище файлов, из которого сайт будет собираться.

1. Откройте https://github.com/signup
2. Введите почту, пароль, придумайте имя пользователя.
3. Подтвердите почту по письму от GitHub.

### Шаг 2. Создать пустое хранилище для сайта

1. Откройте https://github.com/new
2. **Repository name:** `zvukn-site`
3. Нажмите **Create repository**.
4. Скопируйте адрес созданного хранилища (вид: `https://github.com/ваше-имя/zvukn-site`)
   и передайте его помощнику.

### Шаг 3. Загрузить файлы (это тоже делает помощник, но лучше вместе)

Помощник подготовит проект к загрузке: уберёт лишнее и создаст настройки для
Netlify. После этого файлы загружаются одним из двух способов:

- **Через программу-помощника** (быстрее): помощник создаст файл
  `ЗАГРУЗИТЬ-НА-GITHUB.command`, вы запускаете его двойным щелчком — файлы
  уезжают в хранилище. Вас попросят один раз вставить «ключ доступа»,
  который выдаёт GitHub (помощник покажет, где его взять).
- **Через сайт GitHub** (без команд): на странице хранилища нажать
  **Add file → Upload files** и перетащить папки проекта, **кроме** папок
  `node_modules` и `_site`.

### Шаг 4. Подключить хранилище к Netlify

1. Откройте https://app.netlify.com и войдите.
2. Если сайт уже есть: **Site configuration → Build & deploy → Link repository**
   → выберите GitHub → выберите `zvukn-site`.
   Если сайта нет: **Add new site → Import an existing project → GitHub**.
3. Параметры сборки Netlify подставит сам из файла `netlify.toml`:
   команда сборки `npm run build`, папка сайта `_site`.
4. Нажмите **Deploy**. Через минуту сайт обновится.
5. Чтобы адрес остался прежним (`zvukn-school.netlify.app`), в Netlify:
   **Domain management → Add domain alias** и добавьте этот адрес.

### Шаг 5. Включить вход по почте и паролю

Это то, чем будет пользоваться владелец сайта.

1. В Netlify откройте сайт → **Site configuration → Identity → Enable Identity**
   (включить).
2. Там же: **Registration → Invite only** (вход только по приглашению).
3. Затем **Site configuration → Identity → Services → Git Gateway → Enable**.
4. Откройте **Identity → Invite users** и впишите почту владельца сайта.
5. Владелец получит письмо, перейдёт по ссылке и задаст свой пароль.

### Шаг 6. Проверить

1. Откройте `https://zvukn-school.netlify.app/admin/`
2. Войдите почтой и паролем владельца.
3. Поменяйте любую мелочь (например, цену курса) и нажмите **Publish**.
4. Через минуту проверьте сайт — изменение должно появиться.

---

## Что делает помощник (вам делать не нужно)

- Создаёт файлы настроек для Netlify: `netlify.toml`, `.nvmrc`, `.gitignore`.
- Убирает из проекта лишнее (сборку `_site`, служебную папку `node_modules`),
  чтобы в хранилище не уезжали лишние файлы.
- Готовит панель управления (`admin/`) — она уже собрана.
- Готовит и запускает файл загрузки на GitHub, показывает, где взять ключ доступа.
- Проверяет, что после подключения сайт собирается без ошибок.

---

## Если что-то не получилось

- **Сайт не обновился после «Publish»** — подождите 2 минуты и обновите
  страницу. Если не помогло: Netlify → **Deploys** → посмотрите последнюю
  сборку, там написано, что не получилось.
- **Не приходит письмо-приглашение владельцу** — проверьте папку «Спам».
  Письмо приходит с адреса Netlify.
- **Забыли пароль** — на странице `/admin/` есть ссылка восстановления пароля.
- **Сайт перестал открываться** — в Netlify нажмите **Deploys → выберите
  предыдущую удачную сборку → Publish deploy**. Сайт вернётся к рабочему виду.
